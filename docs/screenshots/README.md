# Ekran Görüntüleri / Screenshots

README dosyalarında kullanılan ekran görüntüleri bu klasörde tutulur.
Screenshots used in the README files are stored in this folder.

## Beklenen dosya adları / Expected file names

| Dosya / File | İçerik / Content |
|--------------|------------------|
| `01-liste.png` | Ana kayıt listesi — başlık, arama, tablo, işlem butonları |
| `02-detay-modali.png` | Detay modalı (göz butonu) |
| `03-form-modali.png` | Yeni kayıt / düzenleme formu |
| `04-sayfalama.png` | Tam sayfa görünümü — tablo, sayfalama ve alt bilgi |
| `05-arama.png` | Arama sonucu — filtrelenmiş tablo |

## Yeni ekran görüntüsü eklerken / When adding new screenshots

- Genişlik **1200–1400 px** arası olsun; daha büyüğü README'de gereksiz yer kaplar.
- **PNG** formatı tercih edin (metin keskin görünür).
- Dosya boyutunu 500 KB altında tutmaya çalışın.
- Gerçek veri değil, `crud.sql` içindeki örnek veriler görünsün.
